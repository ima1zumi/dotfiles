# Neovim Tutor

Git リポジトリで `:TutorStart` または `:TutorStart claude` を実行すると、右側の terminal に学習用の Claude Code を auto mode で起動します。Codex を使う場合は `:TutorStart codex` を実行します。CLI は事前にインストール・認証しておいてください。Neovim 0.11 以降を想定しています。

## Claude Code での使い方

1. 学習するリポジトリのファイルを Neovim で開きます。
2. `:TutorStart` を実行します。初回に CLI の認証や信頼確認が表示された場合は対応してください。
3. Claude Code の最初の質問に答え、取り組む課題や困っていることを伝えます。学習目標を保存している場合は「learning.md を読んで、続きから進めたいです」と頼めます。
4. `<C-\><C-n>` で terminal の入力から抜け、`<C-w>h` などでコードのウィンドウに移動します。
5. コードを書いて保存したら、`:TutorStart` で同じ会話に戻り、差分の確認を頼みます。

キーマップは追加しません。起動後は普通に会話してください。

- 「今日は Ruby の二分探索を学びたいです」と目標を伝えます。
- 自分でコードを書いて保存し、「今の Git 差分を見て、ヒントを一つください」と頼みます。
- 「この入力なら 3 が返ると予想しましたが、実際は nil でした」と予想と結果を伝えます。
- 区切りに「理解できているか、少し条件を変えた問題を出してください」と頼めます。

terminal から Neovim の操作に戻るには `<C-\><C-n>` を押します。`:TutorHide` で会話のウィンドウを閉じ、同じリポジトリで同じ `:TutorStart` を実行すると会話に戻れます。通常のウィンドウ移動も使えます。セッションはリポジトリと CLI ごとに保持します。

CLI を終了したり terminal バッファを削除したりした後は、新しい会話が始まります。Neovim 終了後の自動復元はありません。

Claude Code は `--permission-mode auto`、Codex は `--sandbox read-only` で起動します。Claude Code を読み取り専用に制限する構成ではありませんが、学習用の初期指示ではファイル編集や commit を行わないよう伝えます。CLI の通常の認証・信頼確認・承認画面には手動で対応してください。設定変更前から開いている会話には新しい起動オプションが反映されないため、CLI を終了してから起動し直してください。

Git が見られるのは保存したファイルです。未保存の内容、選択範囲、テスト出力は自動送信しません。差分の監視や自動レビューも行いません。必要な出力は会話に貼り付けてください。

学習方針は隣の `prompt.md` にまとめています。変更は次に起動する新しい会話から反映されます。プロジェクト固有の目標や振り返りは、そのリポジトリの `learning.md` に任意で残せます。

会話は明るく好奇心旺盛で、好きなことや挑戦を応援してくれる、対等な友達のような雰囲気にしています。作りたいものに興味を持ち、発見を一緒に喜びながら、小さな一歩を考える方針です。疲れているときは落ち着いた調子にし、説明がほしいときは質問だけを繰り返さず答えます。口調や会話例も `prompt.md` で調整できます。

## 学習目標をローカルに残す

目標そのものは `.gitignore` ではなく、学習するリポジトリのルートに `learning.md` として書きます。たとえば次のように、自分の予想と確認できたことを残します。

```markdown
# 学習目標
Ruby で二分探索を書き、探索範囲が必ず狭まる理由を説明できるようになる。

## 今取り組んでいること
要素が二つの場合の境界条件を調べている。

## 予想と結果
中央を更新すれば終了すると思ったが、同じ範囲を繰り返していた。

## 次に確かめること
探索範囲の長さを各反復で書き出す。
```

個人用の記録として Git に含めたくない場合は、`git rev-parse --git-path info/exclude` が示すファイルに `/learning.md` を追記します。通常は `.git/info/exclude` です。この方法なら共有する `.gitignore` を変更せず、自分の環境だけで除外できます。チーム共通で除外する場合は、リポジトリの `.gitignore` に `/learning.md` を追記してください。

すでに追跡されているファイルは、除外設定を追加しても追跡されたままです。学習記録を commit して残す運用なら、除外する必要はありません。

除外した `learning.md` は `git status` や diff に出ませんが、Tutor の初期指示には直接参照する方針を含めています。Git の除外設定は AI からファイルを隠す設定ではありません。Tutor が目標や除外設定を自動作成・更新することはありません。
